Where is the robot?

VisionBot itself runs on the robot’s computer; this page only shows what it sees. On that computer, the address is http://127.0.0.1:8770 (your browser may ask to allow access to devices on your local network). From another device, open a secure tunnel on the robot’s computer, for example cloudflared tunnel --url http://127.0.0.1:8770, and paste the https:// address it prints. The access key is in the .env file next to VisionBot.
